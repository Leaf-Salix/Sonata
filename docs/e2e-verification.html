1. 端到端流程是什么

Sonata 的端到端流程是：真实 PyPTO DSL 程序 → PyPTO 编译流水线 → Sonata 分析 → HostBuildGraphPlan → simpler runtime 执行

@pl.program
PyPTO DSL
→
pypto passes

→
PostSimplify
IR dump
→
sonata_analyze()
eligibility + regions
→
HostBuildGraph
Plan
→
simpler runtime
a2a3sim

3. 如何复现

前置条件

  • Python 3.11+
  • PyPTO 已 clone 到 pypto-sonata/upstream/pypto/
  • PTO-ISA 和 ptoas 已安装
1

创建并配置 venv

# 创建 venv
python3.11 -m venv .venv-sonata

# 在 activate 末尾添加（一次性）
echo 'export PTO_ISA_ROOT=/path/to/ptoisa' >> .venv-sonata/bin/activate
echo 'export PTOAS_ROOT=/path/to/ptoas' >> .venv-sonata/bin/activate
echo 'export PATH="$PTOAS_ROOT/bin:$PATH"' >> .venv-sonata/bin/activate

# 激活
source .venv-sonata/bin/activate
2

安装依赖

# 安装 pypto（编译器层）
cd pypto-sonata/upstream/pypto
pip install scikit-build-core nanobind cmake ninja numpy torch --index-url https://download.pytorch.org/whl/cpu
pip install --no-build-isolation .

# 安装 simpler（运行时层）— 必须从 runtime/ 目录
cd runtime
pip uninstall simpler -y
pip install --no-build-isolation .

# 安装测试依赖
pip install pytest pytest-xdist pytest-forked
3

运行 sonata unit tests（不需要 PyPTO）

cd pypto-sonata
PYTHONPATH=src python -m pytest tests/sonata -q
# 预期: 506 passed
