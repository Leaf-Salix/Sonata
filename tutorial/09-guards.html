Tutorial 9 - Guard 条件系统

提问：什么是 Guard？

Sonata 的 Score 是在编译时生成的静态执行计划。但编译时做出的假设 （比如 "batch_size = 32"）可能在运行时不再成立。Guard 就是这些假设的运行时断言。

类比：你根据"今天 32°C"规划了户外烧烤。Guard 就是"如果下雨就取消"。 你不需要重新规划——只需要检查一个条件，决定是继续执行还是切换到 Plan B。

v0.1-v0.9 只有一种 Guard：ShapeAssumption——假设输入张量的形状固定。 v0.10 将其抽象为 GuardCondition ABC，支持任意类型的运行时约束。

提问：GuardCondition 的接口是什么？

from abc import ABC, abstractmethod

class GuardCondition(ABC):
    symbol: str          # 可读标识符，如 "batch_size"
    severity: GuardSeverity  # "soft" 或 "hard"

    @abstractmethod
    def evaluate(self, runtime_values: dict[str, Any]) -> bool:
        """O(1) 运行时检查。返回 True = 条件满足。"""
        ...

所有 Guard 都必须实现 evaluate() 方法，且必须是 O(1)—— 因为每次 cache 查找都会执行所有 Guard 的 evaluate。

提问：severity soft 和 hard 有什么区别？

Severity含义失效动作例子
hard结构级变化REPLAN：Score 和 PlanHandle 都失效，需要重新编译输入维度数变了
soft参数级变化INVALIDATE_HANDLE：只失效 PlanHandle，Score 仍可用batch_size 从 32 变成 64
from sonata.guard import GuardSeverity, GUARD_SEVERITY_SOFT, GUARD_SEVERITY_HARD

# hard（默认）：形状假设通常用 hard
guard = ShapeAssumption(symbol="batch_size", dims=(32,), severity=GUARD_SEVERITY_HARD)

# soft：参数级约束
guard = ShapeAssumption(symbol="seq_len", dims=(128,), severity=GUARD_SEVERITY_SOFT)

提问：ShapeAssumption 现在怎么用？

ShapeAssumption 现在继承自 GuardCondition，保持向后兼容但已标记 deprecated：

import warnings
warnings.simplefilter("always")  # 开启 deprecation 警告

# 旧写法（会触发 DeprecationWarning）
from sonata.score import ShapeAssumption
old_guard = ShapeAssumption(symbol="N", dims=(128,))

# 新写法（推荐）
from sonata.guard import ShapeAssumption, GUARD_SEVERITY_HARD
new_guard = ShapeAssumption(symbol="N", dims=(128,), severity=GUARD_SEVERITY_HARD)
迁移提示：ShapeAssumption 将在 v0.11 正式版移除。 请使用 GuardCondition 子类代替。详见 docs/user-guide/guards-migration.md。

提问：GuardEvaluator 是什么？

GuardEvaluator 是运行时评估器，负责检查一组 Guard 是否满足：

from sonata.guard import GuardEvaluator, InvalidateAction

evaluator = GuardEvaluator()

# 检查单个 Guard
runtime_values = {"batch_size": 32, "seq_len": 128}
satisfied, action = evaluator.evaluate(guard, runtime_values)
# satisfied=True, action=InvalidateAction.REPLAN（如果是 hard guard）

# 检查多个 Guard
all_ok, results = evaluator.evaluate_all([guard1, guard2], runtime_values)
# all_ok=True if 全部满足
# results=[(guard1, True, action1), (guard2, True, action2)]

提问：区域级 Guard 评估是什么？

v0.11 的关键新功能：evaluate_region() 可以对整棵 RegionTree 子树 评估所有 Guard，返回一个 GuardStatus：

from sonata.guard import GuardEvaluator
from sonata.plan_handle import GuardStatus

evaluator = GuardEvaluator()

# 评估某个区域节点及其所有子孙的 Guard
status = evaluator.evaluate_region(region_node, runtime_values)

if status == GuardStatus.ALL_SATISFIED:
    print("所有 Guard 满足，可以使用缓存")
elif status == GuardStatus.PARTIAL_FAILED:
    print("部分 soft guard 失效，需要更新 PlanHandle")
elif status == GuardStatus.ALL_FAILED:
    print("hard guard 失效，需要重新编译")

短路逻辑：如果遇到 hard guard 失效，立即返回 ALL_FAILED， 不再检查后续 Guard。

提问：GuardSelector 是什么？怎么防止 over-guarding？

如果一个图有 100 个参数，就会有 100 个 Guard。 但 fingerprint 包含所有 Guard 的哈希，这意味着只要任何一个参数变化， fingerprint 就会变——缓存命中率极低。这叫做 over-guarding。

GuardSelector 从所有 Guard 中选出最重要的 Top-K：

from sonata.guard import EntryParamGuardSelector

# 选择最重要的 10 个 Guard
selector = EntryParamGuardSelector(top_k=10)
critical_guards = selector.select(all_guards)

# 带优先级
selector = EntryParamGuardSelector(
    top_k=5,
    priority_symbols=("batch_size", "seq_len"),
)
selected = selector.select(all_guards)

也可以用 select_region_guards() 一步完成选择和密度检查：

from sonata.guard import GuardEvaluator

evaluator = GuardEvaluator()
selected = evaluator.select_region_guards(
    region_node,
    selector=EntryParamGuardSelector(top_k=10),
    density_threshold=50,  # 超过 50 个 Guard 时发出警告
)

提问：InvalidateAction 有哪几种？

Action含义触发条件
REPLANScore 和 PlanHandle 都失效，需要重新提取和编译hard guard 失效
INVALIDATE_HANDLE只失效 PlanHandle，Score 可重用soft guard 失效
UPDATE_IN_PLACE参数级更新，无需重建（预留，当前未使用）

提问：GuardInvalidator 和 GuardEvaluator 有什么区别？

# GuardEvaluator: 评估 Guard 是否满足
satisfied, action = evaluator.evaluate(guard, runtime_values)
# → 告诉你"是否满足"+"如果失效该怎么做"

# GuardInvalidator: 决定失效策略
invalidator = GuardInvalidator()
action = invalidator.invalidate(guard, reason="shape changed")
# → 告诉你"该执行什么恢复动作"

# 批量决策
results = evaluator.evaluate_all(guards, runtime_values)
overall_action = invalidator.invalidate_all(results)
# → 如果有 hard 失效 → REPLAN
# → 只有 soft 失效 → INVALIDATE_HANDLE

提问：怎么自定义 Guard 类型？

from sonata.guard import GuardCondition, GuardSeverity

class MemoryBudgetGuard(GuardCondition):
    """检查运行时内存不超过预算。"""

    def __init__(self, budget_bytes: int):
        super().__init__(symbol="memory_budget", severity=GuardSeverity.HARD)
        self.budget_bytes = budget_bytes

    def evaluate(self, runtime_values: dict) -> bool:
        used = runtime_values.get("memory_used", 0)
        return used <= self.budget_bytes

    def to_dict(self) -> dict:
        base = super().to_dict()
        base["type"] = "MemoryBudgetGuard"
        base["budget_bytes"] = self.budget_bytes
        return base

# 使用
guard = MemoryBudgetGuard(budget_bytes=1024 * 1024 * 512)  # 512 MB
ok = guard.evaluate({"memory_used": 100 * 1024 * 1024})  # True
设计原则：
  • Guard 必须是 frozen=True（不可变）
  • evaluate() 必须是 O(1)
  • 新增 Guard 类型只需实现 evaluate()，可选覆盖 to_dict() / from_dict()
