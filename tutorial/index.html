Sonata Tutorial 索引

欢迎来到 Sonata tutorial！本教程将带你了解 Sonata 的核心概念、架构和使用方法。

目标读者：本教程面向有 PyPTO 使用经验的开发者。 如果你是 PyPTO 新手，建议先阅读 PyPTO 官方文档。
前置知识：学习本教程前，你应该了解：
  • Python 3.10+ 基础语法
  • PyPTO 的基本概念（IR、pass pipeline、codegen）
  • 昇腾 NPU 的基本架构（AICPU、AIC/AIV 核心）
如果你不熟悉这些术语，可以查看 术语表。

环境准备

在开始学习前，请确保完成以下步骤：

  1. Python 环境：确保 Python 3.10+ 已安装
  2. PyPTO 安装：按照 PyPTO 官方文档 安装 PyPTO
  3. Sonata 安装： 
    # 克隆 Sonata 仓库
git clone https://github.com/Leaf-Salix/pypto-sonata.git
cd pypto-sonata

# 创建虚拟环境（推荐）
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# 或 .venv\Scripts\activate  # Windows

# 安装 Sonata（开发模式）
PYTHONPATH=src pip install -e .
  4. 验证安装： 
    # 运行 Sonata 测试
PYTHONPATH=src python -m pytest tests/sonata -q

    如果看到类似 "792 passed" 的输出，说明安装成功。

macOS 用户注意：PyPTO 的 simpler 运行时在 macOS arm64 上编译会失败。 但 Sonata 核心代码和测试可以在 macOS 上正常运行。 如果你需要运行 st 测试（需要 simpler），请使用 Linux 或 CI 环境。
提示：如果你只想了解 Sonata 的概念而不打算运行代码，可以直接跳到下面的教程。

学习路径

Sonata 的学习分为三个层次，由浅入深：

第一层：入门（30 分钟）

目标：理解 Sonata 是什么，能创建和使用 Score。

  1. Tutorial 0: Sonata 是什么？ - 了解整体架构和解决的问题
  2. Tutorial 1: Score 数据模型 - 了解 Sonata 的核心产物
  3. Tutorial 11: Pipeline - 了解如何使用 API（最重要）

学完后你能：创建 Score、使用 sonata_analyze()、理解 Sonata 的基本流程。

第二层：进阶（1-2 小时）

目标：理解 Sonata 的核心机制，能调试和扩展。

  1. Tutorial 2: Eligibility - 了解 Sonata 如何判断程序是否适合静态调度
  2. Tutorial 3: 依赖策略 - 了解任务之间的依赖关系分析
  3. Tutorial 8: Region Tree - 了解层次化区域管理
  4. Tutorial 9: Guard 条件系统 - 了解形状假设和守卫条件
  5. Tutorial 10: 内存规划 - 了解内存分配策略

学完后你能：理解 Sonata 的内部机制、调试 eligibility 问题、扩展 guard 条件。

第三层：深入（2-3 小时）

目标：完全理解 Sonata 的实现细节，能修改和贡献代码。

  1. Tutorial 4: 序列化与 Fingerprint - 了解 Score 的序列化和缓存机制
  2. Tutorial 5: Storage Keys 与审计 - 了解存储分析和审计元数据
  3. Tutorial 6: Fallback Reason - 了解回退机制和工业界经验
  4. Tutorial 7: 运行测试 - 了解如何验证功能和当前状态
  5. Tutorial 12: RUNTIME_CONFIG 注入 - 了解与 PyPTO 运行时的集成
  6. Deep Dive 系列 - 深入了解每个模块的实现细节

学完后你能：完全理解 Sonata 的实现、修改核心代码、添加新功能。

建议：新手从第一层开始，学完后再进入第二层。 如果你只想快速使用 Sonata，完成第一层就够了（30 分钟）。 如果你想深入理解或贡献代码，需要完成所有三层。
