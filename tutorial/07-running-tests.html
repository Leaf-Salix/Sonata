Tutorial 7 - 运行测试与当前状态

提问：怎么跑测试？

纯 Sonata 测试（不需要 PyPTO）：

cd pypto-sonata
PYTHONPATH=src python -m pytest tests/sonata

包含 PyPTO 兼容性测试：

cd pypto-sonata
PYTHONPATH=src:upstream/pypto/python python -m pytest tests/sonata tests/pypto_cases

提问：纯 Sonata 测试怎么模拟 IR 节点？

用简单的 dataclass 模拟 IR，刚好有 Sonata 需要的字段：

@dataclass
class Function:
    name: str
    body: Any

@dataclass
class Call:
    op: str
    args: tuple[Any, ...] = ()
    arg_directions: tuple[Any, ...] = ()

@dataclass(frozen=True)
class Var:
    name_hint: str
    type: Any | None = None

@dataclass(frozen=True)
class TensorType:
    shape: tuple[Any, ...]

提问：怎么写一个 Score 验证测试？

from sonata import Score, Task, Dependency, RuntimeTarget

def test_score_validate_rejects_unknown_dependency_target():
    score = Score(
        name="invalid",
        runtime_target=RuntimeTarget(
            runtime="host_build_graph",
            function_name="build_invalid_graph",
        ),
        tasks=(Task(task_id=0, func_id=0, core_type="aiv"),),
        dependencies=(Dependency(producer=0, consumer=2),),  # 2 不存在
    )
    result = score.validate()
    assert not result.eligible
    assert result.reasons == ("dependency consumer is unknown: 2",)
    assert result.reason_details[0].code == "score_validation_failed"

提问：当前有什么限制？

坦诚说明：以下列出当前 Sonata 的主要限制，帮助你评估项目成熟度。

功能限制

限制影响缓解/计划
无端到端性能数据 虽有 benchmark 基线，但未在真实 NPU 上跑端到端 v0.12+ 真机 benchmark
ILP/CP 求解器未接入 内存规划只有贪心策略，对大图不是最优 ConstraintSolver 接口已预留，v0.12+ 接入
Group/Spmd 不支持 PyPTO 的 Group/Spmd 函数会展开成多个 task，Sonata 只按 Call 提取一个 后续版本扩展
per-region Score 提取为 placeholder check_region_eligibility 中的 per-region Score 目前是空占位 v0.12+ 接入真实提取

架构风险

  • PyPTO pass stage 耦合：Sonata 用 getattr() 访问 PyPTO IR 字段。如果 PyPTO 改了字段名或 pipeline 顺序，Sonata 会静默降级。通过 adapter contract test 缓解。
  • RuntimeTarget 数据流未打通：Sonata 准备好了 Score，但 PyPTO 的配置生成系统还没有"读取计划"的接口。
