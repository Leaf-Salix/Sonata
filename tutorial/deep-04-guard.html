GuardSeverity — 严重程度

@dataclass(frozen=True)
class GuardSeverity:
    value: str  # "soft" 或 "hard"

    @property
    def requires_replan(self) -> bool:
        return self.value == "hard"

GUARD_SEVERITY_SOFT = GuardSeverity("soft")
GUARD_SEVERITY_HARD = GuardSeverity("hard")

为什么用 dataclass 而不是 Enum？因为 severity 需要作为 frozen dataclass 的字段值， 而 Enum 在某些序列化场景下行为不可预测。两个预定义实例 GUARD_SEVERITY_SOFT 和 GUARD_SEVERITY_HARD 是模块级常量。

GuardCondition — 抽象基类

@dataclass(frozen=True)
class GuardCondition(ABC):
    symbol: str
    severity: GuardSeverity

    @abstractmethod
    def evaluate(self, runtime_values: dict[str, Any]) -> bool: ...

    def to_dict(self) -> dict[str, Any]:
        return {"symbol": self.symbol, "severity": self.severity.value}

    @classmethod
    def from_dict(cls, data: dict) -> "GuardCondition":
        # 默认 fallback 到 ShapeAssumption
        severity = GuardSeverity(data["severity"])
        return ShapeAssumption(symbol=data["symbol"], dims=(), severity=severity)

__eq__ 和 __hash__ 的设计

def __eq__(self, other):
    if not isinstance(other, GuardCondition): return False
    return self.symbol == other.symbol and self.severity == other.severity

def __hash__(self):
    return hash((self.symbol, self.severity))

只比较 symbol 和 severity，不比较子类特有字段。 这意味着两个不同子类、相同 symbol 和 severity 的 Guard 被视为相等。 这是有意的设计——Guard 的身份由 symbol 决定，severity 决定失效行为。

from_dict 的默认行为

设计决策：GuardCondition.from_dict() 默认创建 ShapeAssumption(symbol=..., dims=(), severity=...)。 子类应该覆盖 from_dict 来提供正确的反序列化。 to_dict 返回的 {"type": "ShapeAssumption", ...} 中的 type 字段由子类添加，基类不处理。

__post_init__ 的 deprecation 逻辑

def __post_init__(self):
    if not self._warning_emitted:
        object.__setattr__(self, '_warning_emitted', True)
        warnings.warn(
            "ShapeAssumption is deprecated since v0.10 ...",
            DeprecationWarning, stacklevel=2
        )

每次创建都会发出警告——因为 _warning_emitted 是 init=False，每个新实例都从 False 开始。 这不是"全局只警告一次"，而是"每次实例化都警告"。

evaluate 的逻辑

def evaluate(self, runtime_values: dict) -> bool:
    runtime_shape = runtime_values.get(self.symbol)
    if runtime_shape is None:
        return False  # 缺少该符号 → 不满足
    if isinstance(runtime_shape, list):
        runtime_shape = tuple(runtime_shape)
    return runtime_shape == self.dims

精确匹配：(32,) != (32, 64)，(32, 64) != (64, 32)。 不支持部分匹配或范围匹配。

InvalidateAction — 失效动作枚举

class InvalidateAction(Enum):
    REPLAN = "replan"                    # Score + PlanHandle 都失效
    INVALIDATE_HANDLE = "invalidate_handle"  # 只失效 PlanHandle
    UPDATE_IN_PLACE = "update_in_place"  # 预留，当前未使用

两个便捷方法：

action.requires_full_replan()  # == REPLAN
action.is_conservative()       # == REPLAN or INVALIDATE_HANDLE

GuardEvaluator — 运行时评估器

evaluate — 单个 Guard 评估

def evaluate(self, guard, runtime_values) -> tuple[bool, InvalidateAction]:
    try:
        satisfied = guard.evaluate(runtime_values)
        action = InvalidateAction.REPLAN if guard.severity.requires_replan \
                 else InvalidateAction.INVALIDATE_HANDLE
        return satisfied, action
    except Exception as e:
        return False, InvalidateAction.REPLAN  # 异常 → 保守处理

关键设计：即使 Guard 满足（satisfied=True），返回的 action 仍然是 该 severity 对应的最坏动作。action 代表"如果这个 Guard 失效了会怎样"， 而不是"当前需要执行什么"。

evaluate_all — 批量评估

def evaluate_all(self, guards, runtime_values) -> tuple[bool, list]:
    results = []
    all_satisfied = True
    for guard in guards:
        satisfied, action = self.evaluate(guard, runtime_values)
        results.append((guard, satisfied, action))
        if not satisfied:
            all_satisfied = False
    return all_satisfied, results

不短路——即使第一个 Guard 失效，仍然检查所有 Guard。 这使得调用方能看到完整的评估结果。

evaluate_region — 区域级评估（v0.11）

def evaluate_region(self, node: RegionTreeNode, runtime_values) -> GuardStatus:
    guards = []
    def _collect(n):
        if n.score is not None:
            guards.extend(n.score.shape_assumptions)
        for child in n.children:
            _collect(child)
    _collect(node)

    if not guards:
        return GuardStatus.ALL_SATISFIED

    any_failed = False
    for guard in guards:
        satisfied, action = self.evaluate(guard, runtime_values)
        if not satisfied:
            if action == InvalidateAction.REPLAN:
                return GuardStatus.ALL_FAILED  # 短路！
            any_failed = True
    return GuardStatus.PARTIAL_FAILED if any_failed else GuardStatus.ALL_SATISFIED
与 evaluate_all 的区别：evaluate_region 会短路—— 遇到 hard guard 失效立即返回 ALL_FAILED，不再检查后续 Guard。 evaluate_all 不短路——始终检查所有 Guard。 这是因为 evaluate_region 用于运行时决策（需要快速返回）， 而 evaluate_all 用于诊断（需要完整信息）。

select_region_guards — Guard 选择（v0.11）

def select_region_guards(self, node, selector=None, *, density_threshold=50):
    guards = []
    def _collect(n):
        if n.score is not None:
            guards.extend(n.score.shape_assumptions)
        for child in n.children:
            _collect(child)
    _collect(node)

    exceeds, count = check_guard_density(guards, warning_threshold=density_threshold)
    if exceeds:
        warnings.warn(f"Region guard density {count} exceeds threshold ...")

    if selector is None:
        selector = EntryParamGuardSelector()
    return selector.select(guards)

GuardInvalidator — 失效策略决策

class GuardInvalidator:
    def __init__(self, default_action=InvalidateAction.REPLAN):
        self.default_action = default_action

    def invalidate(self, guard, reason="") -> InvalidateAction:
        if guard.severity.requires_replan:
            return InvalidateAction.REPLAN
        return InvalidateAction.INVALIDATE_HANDLE

    def invalidate_all(self, results) -> InvalidateAction:
        for guard, satisfied, action in results:
            if not satisfied and guard.severity.requires_replan:
                return InvalidateAction.REPLAN
        return InvalidateAction.INVALIDATE_HANDLE

invalidate_all 的策略：遍历结果，只要有一个 hard 失效就返回 REPLAN。 否则返回 INVALIDATE_HANDLE。注意它只看不满足的 Guard。

GuardSelector — 过度防护缓解

GuardSelector ABC

class GuardSelector(ABC):
    @abstractmethod
    def select(self, guards, runtime_info=None) -> list[GuardCondition]: ...

EntryParamGuardSelector — 默认策略

@dataclass(frozen=True)
class EntryParamGuardSelector(GuardSelector):
    top_k: int | None = None
    priority_symbols: tuple[str, ...] = field(default_factory=tuple)

    def select(self, guards, runtime_info=None):
        guards_list = list(guards)
        # 1. 先选 priority_symbols 中的
        selected = [g for g in guards_list if g.symbol in self.priority_symbols]
        # 2. 再添加剩余的（保持原始顺序）
        remaining = [g for g in guards_list if g.symbol not in self.priority_symbols]
        selected.extend(remaining)
        # 3. top_k 截断
        if self.top_k is not None and len(selected) > self.top_k:
            selected = selected[:self.top_k]
        return selected

设计思路：入口参数（如 batch_size、seq_len）比中间 tensor 更可能变化。 优先选择入口参数的 Guard 可以在不牺牲安全性的前提下提高缓存命中率。

check_guard_density — 密度检查

def check_guard_density(guards, warning_threshold=50, logger=None) -> tuple[bool, int]:
    count = sum(1 for _ in guards)
    exceeds = count > warning_threshold
    if exceeds and logger:
        logger(warning_threshold, f"Guard density {count} exceeds threshold ...")
    return exceeds, count

注意：sum(1 for _ in guards) 而不是 len(list(guards))—— 因为它接受 Iterable，不保证有 len。

迁移工具（Phase 6）

shape_assumption_to_guard_condition

def shape_assumption_to_guard_condition(sa, severity=None):
    if not isinstance(sa, ShapeAssumption):
        raise TypeError(...)
    warnings.warn("ShapeAssumption is deprecated ...", DeprecationWarning)
    if severity is not None and sa.severity != severity:
        return ShapeAssumption(symbol=sa.symbol, dims=sa.dims, severity=severity)
    return sa  # 已经是 GuardCondition，直接返回

本质是 identity 函数——ShapeAssumption 已经是 GuardCondition 子类。 这个函数的意义是发出 deprecation 警告，引导用户迁移到直接使用 GuardCondition。
